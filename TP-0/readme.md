# tp_devops

Simple HTTP server that returns request headers as JSON on `GET /ping`.

## Requirements

- Node.js

## Installation

```bash
git clone https://github.com/Emery711Git/tp_devops.git
cd devops
```

## Usage

### Default port (3000)
```bash
npm start
```

## Test

```bash
curl http://localhost:3000/ping
```
